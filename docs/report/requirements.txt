# The report's numbers are checked by report-kit's `figures` command. The pin is
# a tag, not a branch: the 500 marks in these documents were verified against one
# version of the resolver, and `@master` would quietly become a different one.
#
#   pip install -r docs/report/requirements.txt
#   cd docs/report && report-kit figures check
#
# Bump deliberately, then re-run the check and read the mark count before
# treating the new version as equivalent.
#
# The [charts] extra pulls in matplotlib, which `report-kit charts` needs to
# render `charts/*.csv` into SVGs beside them, as `charts/charts.yaml` says.
# Only to render: `charts --check` draws nothing and needs nothing extra.
#
#   cd docs/report && report-kit charts --all && report-kit charts --check
