# The three http_ names assumed the Go API's exporter — it has none (confirmed
# twice, 2026-09-02: no /metrics endpoint at all). Unblocked 2026-09-05 via
# Cilium's own Envoy proxy instead: traffic to `api` crosses
# cilium-gateway-cilium-gateway, and its Envoy sidecars already export
# envoy_cluster_upstream_rq_* per upstream cluster (scrape job `cilium-envoy`,
# deploy/k8s/platform/monitoring/values/prometheus.yaml) — a drop-in
# replacement, no application change needed. Confirmed live against real
# inference-point traffic (r050, r200): non-zero, per-request counts, real
# histogram buckets, real envoy_response_code_class="5" counts. One unit
# change: Envoy's histogram is milliseconds, not seconds — no /1000 needed
# here, unlike the original http_request_duration_seconds_bucket assumption.
# envoy_cluster_upstream_rq_total/_xx/_time_bucket are cumulative counters
# across the whole cluster lifetime, not per-point — every query below is
# wrapped in rate(), same as the original http_ version, so this is fine.
