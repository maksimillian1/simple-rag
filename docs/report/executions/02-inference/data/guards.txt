# {rate_floor} is substituted by the runner: offered rate × SERVED_RATE_FLOOR,
# and the multiplier is a constant in run-inference-point.py. A per-point value
# enters a frozen file only through a named substitution, never as arithmetic
# written here.
#
# The sustained rate is set by the latency target, not the throughput ceiling
# → K3. A served rate below the offered one means the generator queued its own
# excess, and the percentile then describes the queue.
